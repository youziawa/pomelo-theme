用 Markdown 写出层次清晰的文章

2026-08-24 456 words ~2 min Updated: 2026-08-24
主题教程 内容创作

一篇技术文章不需要很花哨，但需要让读者一眼分清结论、步骤、代码和补充信息。Pomelo 的正文宽度、行高和标题层级都按长文阅读做了约束。

标题与段落

正文建议从二级标题开始，一级标题已经由文章标题承担。段落保持简短，复杂论点拆成小节，读起来会更轻松。

强调与链接

使用 加粗 标记结论，用 斜体 表示语气上的补充。链接会保留霓虹青色和下划线偏移，例如 Hexo 官方文档。

列表

  • 先说明要解决的问题。
  • 再给出可以复制的步骤。
  • 最后补充边界条件和排错方向。
  1. 建立最小可用示例。
  2. 验证预期效果。
  3. 再扩展到真实内容。

引用块适合放提醒、经验结论和来源摘要。它不该取代正文，而是给读者一个短暂停靠的位置。

表格与代码

参数较多时，表格比连续段落更适合扫描：

项目 推荐值 说明
正文字号 16px 中文长文阅读的基准
行高 1.8 保持段落呼吸感
卡片圆角 12px 与主题面板一致

行内代码如 theme_color.primary 用于指向具体配置。多行代码使用 fenced code block，主题会提供终端风格背景和复制按钮：

写作检查

发布前，依次确认标题是否准确、代码是否可复制、表格在手机上是否可读，以及外部链接是否指向可信来源。细节并不喧闹，但会让文章显得可靠。
